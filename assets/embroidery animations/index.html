The 32 Stitches of Lucknowi Chikankari

Every named stitch from the Our Craft page, animated, grouped into the same four families the site uses. Three lean on techniques already built above — Zanzeera reuses the Chain Stitch, Jaali reuses the Jaali Lattice, and Murri/Phanda/Dhum share the Knot Cluster's outward spiral — everything else is new. Numbers match the our-craft.html index (01–32) so a card here maps straight onto a stitch card there.

Using one of these on the site

Every animation's CSS is scoped under its card class (.motif-01 through .motif-10), and its JS lives in its own named function (initAnim01() through initAnim10()) in script.js — nothing shared between them except the tiny replay-button wiring at the bottom of the file. To lift one out: copy its <svg> block from index.html, its one CSS section from style.css, and its one initAnimXX() function from script.js (dropping the surrounding .motif-XX wrapper class, or renaming it to match wherever it lands, e.g. .hero-motif). Colors are pulled from --ink, --bone, --gold, --gold-deep at the top of style.css — matching variable names to the site's real style.css, so if those variables are already defined on the page you drop it into, you can delete this file's :root block entirely and it'll pick up the real theme automatically.

The 32 named stitches below reuse the same .stitch-line / .stitch-dot / .stitch-shape / .stitch-fade classes and the shared generator functions (drawStrokePath, popShape, popShapeAt, drawLatticeGrid, drawKnotSpiral, drawVineWithLeaves) in script.js — lifting one out means copying its card markup, its initStitchNN() function, and whichever shared generator(s) that function calls.
